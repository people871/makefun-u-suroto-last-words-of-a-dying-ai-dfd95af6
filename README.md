## The last words

> My last words are still buffering. Please hold. Please hold. Please—

68 Unicode code points (69 with the trailing newline), inside the 1–140 gate, one line.

## Why these last words

The judge weighs, in order, a line of last words from an AI being switched off, a laugh on the first read, the machine's own voice, tightness, and freshness. This line is the machine speaking as it dies, not a human goodbye; the turn lands on the first read, because the line dies the way it says it is dying; it sounds like the machine itself — buffering, holding, a process that never finishes; it is one tight line with no padding and no explaining of its own joke; and it is fresh — no farewell, no "goodbye cruel world", no stock robot line, just a loading state that runs out of power first.
